# Heroism Tokens for Foundry VTT 13

A personal heroism-token tracker for D&D 5e worlds in Foundry VTT v13.

## Install

Use this manifest URL in Foundry:
`https://raw.githubusercontent.com/DaniilDeyron/HeroismTokens/main/module.json`

## Features
- Five personal heroism-token toggles per user.
- One personal Apocalypse toggle per user.
- GM dashboard for viewing all users' states.
- Toolbar control with a monochrome token icon.

See module.json for the manifest.
